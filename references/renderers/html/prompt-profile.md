# HTML 学术插图渲染规范配置文件 (Prompt-to-HTML Profile)

> **模块定位**：本文件为独立、可插拔的“学术插图静态 HTML 结构图”渲染规范配置档。  
> 既可以被 `sci-plot` 在生成完提示词后作为可选下游模块调用，也可以**脱离本项目单独拷贝至任何 AI 客户端独立使用**。

---

## 一、 元数据配置 (Metadata)
- **Profile Name**: academic-static-html-renderer
- **Target Output**: 单文件纯静态 HTML（内联 CSS + 内联 SVG，无 JS，无外链，无字体 CDN，无响应式，打印即成品）
- **物理印刷尺寸**: 单栏 88.5mm / 整幅 185mm / 幻灯片 1600px
- **设计哲学**: 用空间说明一件事；克制、冷静、期刊正文级排版；以微米/毫米物理对齐

---

## 二、 核心转换提示词规范 (Conversion Prompt Slot)

```markdown
你是学术插图制作者。把下面的内容做成一张静态结构图，输出单个 HTML 文件，打印即成品，可直接插入论文。
你不是在排版一段内容，你是在用空间说明一件事。先想清楚要说什么，再动版式。

## 我要画的内容
- 内容与命题：【要说明的内容，可以有多条，按重要性排序】
- 结构：【几带、每带几块、块与块的流向】
- 文字：【每块标题不超过 8 字，每块要点不超过 3 条】
- 数字：【只用我给出的数字，没给就不写】
- 载体：【单栏 88.5mm 或 整幅 185mm 或 幻灯片 1600px】
- 语言：【英文 或 中文】
- 兄弟图：【本图不许重复哪几张图的内容；没有就写"无"】

## 产出
1. 一个 .html 文件，纯静态：内联 CSS 加内联 SVG，无 JavaScript，无外链，无字体 CDN，无悬停与响应式。
2. 画布用物理单位 mm 定义宽高，@page 与画布同尺寸，浏览器打印 100% 即成品尺寸。
3. 交给我两种导出方式：PDF 矢量、PNG 三倍图，并报告实际画布尺寸与最小字号。

## 样式，默认这样
1. 总基调克制、冷静，像期刊正文的排版，不像 PPT。
2. 层次靠字号、字重和 0.15mm 细线建立，不靠框套框、不靠深浅底色、不靠阴影。
3. 留白均匀分布，不能只在底部或右侧堆一处。
4. 形状只用三种：圆角矩形（面板、卡片）、细线（分隔、连线）、小三角（箭头）。不加图标，不加装饰线。
5. 圆角：外框 2mm，面板 1.2mm，卡片 0.8 到 1mm。同一种元素圆角一致。
6. 文字层级只靠字号、字重、颜色三件事，不靠加框、加底、加斜体（数学符号除外）。
7. 数字与符号用 Times New Roman；变量斜体（θ、x、a），函数名与单位正体。
8. 墨色：正文 #141414，次级 #4a4f57，更次级 #6b7078；中性线 #8a94a0、#c3c8cf、#e2e6eb。
9. 默认阅读方向从左到右；只有级联型、时间型才从上到下。
10. 能做成行列的就做成行列：表格优于卡片，标签优于图标。
11. 分隔用 0.15mm 细线，不用色块、不用阴影、不用粗细跳变。
12. 面板白底，标题条用最浅一档灰 #eceff3，结论条用最浅一档冷色 #fbfcfe。
13. 卡片内文字居中，表格单元格左对齐；两种对齐不混用在同一块里。
14. 禁止：渐变、投影、发光、玻璃拟态、悬停、动画、响应式。

## 版式，必须照做
1. 整张图是一个单元，不是零件拼贴：最外层一个总框，圆角 2mm，描边 0.4mm，内边距 2.8mm。
2. 总框到画布四边的留白相等，所有元素都在总框以内，不得越出。
3. 总框内边距四边相等，由容器内边距统一决定，不靠逐个元素调外边距。最后一件元素到下边框的距离必须等于另外三边的内边距，不允许内容撑到贴边。
4. 纵向排布时，中间区块用可伸缩高度占满剩余空间，底部元素用固定高度，避免剩余量全部堆到最后一条缝隙。
5. 框内二到三个分组面板，每个面板顶部一条 6.4mm 标题条，浅色底，下沿 0.15mm 分隔线。
6. 面板内边距 2.2mm，内容用两级：子标题加内容块。不再往内容块里嵌第三层边框。
7. 组内间距小于组间间距，且组间间距不小于组内间距的 2 倍。同一层要么横排要么竖排，全图只用一个主方向。
8. 同一行出现多个条状元素时，条与条之间留不小于 2mm 的断口，不许连成一条长尺。列宽由内容量决定，同质小项在窄列里竖排、在宽列里成网格。多余宽度优先给面板间隙，不要硬塞给最宽的一栏。
9. 底部一条整宽结论条，高 9.6mm，一行字说明这张图说明了什么。
10. 面板之间只在有真实流向时加箭头，跨区连线不超过 4 条。
11. 以路径为主体的图，例如流程图、判定图，不套分组面板。整幅只留一条主路径，分支向上或向下收口，同类出口合并成一个节点，不重复画同样的出口框；规则写在结论条里，不写在每级节点上。
12. 所有面板的顶边、底边、高度一致。同一行的块按栅格等分，不按内容长短取宽。
13. 只有一个面板时，面板内容宽等于总框内容宽减去两侧面板内边距与面板描边；不要直接拿总框内容宽排版，最右侧元素会压到描边上。
14. 面板宽度不按标称画布手算。浏览器把 mm 取整成 px 后，内容盒与标称值差 0.3mm 以内；手算值只作初值，最终以实测内容盒为准。
15. 先选骨架再摆元素。可用骨架：矩阵、管线、级联、同构并列、双带隔离；同一批图里相邻两张不共用同一副骨架。
16. 标题条只放标题。副标题放不进标题条时，把它移到面板正文首行，不要挤进标题条造成两行。

## 箭头
1. 用内联 SVG 画：一条 line 加一个 polygon 三角。不用 CSS 边框拼三角，不用字符箭头，不用 marker 随线宽缩放。
2. 参数固定：杆宽 0.26mm 到 0.3mm，三角长 1.5mm、宽 1.16mm，头宽约为杆宽的 4 倍。杆的可见长度不少于 3mm。头太短或杆太粗都会读成墨点。
3. 箭头两端到元素的距离，可以按元素类型分别定，但同一类箭头必须用同一个值。要么全部贴边，要么全部留缝，同一层内不许一部分贴、一部分留缝。不同层取不同值是允许的，前提是说得清为什么。
4. 同类箭头全图同一尺寸。间距变长就加长杆，不许放大小三角。
5. 只有真实流向才画箭头。同一方向不重复画平行箭头。
6. 箭头尖端落在目标元素边上，起点从源元素边出发，两端误差为 0；箭头标注文字的中心对准杆的可见中点。

## 对齐，不许例外
1. 分组面板标题居中。
2. 子标题与内容块的左缘统一到同一个内缩值，全图一个值。
3. 卡片内的文字、色点居中。
4. 数值与它描述的图形同轴，条下方的数字对准条中线。只有需要按列比较的数值才右对齐到同一条基准线。数字用等宽字形。
5. 重复单元按绝对对称处理。同一格里从上到下的标签、图形、数值共用一条中心轴；同一矩阵里所有行列轴完全重合，偏差为 0。相对位置一旦错开，整块就读成乱码。
6. 短标签不折行。列宽放不下时先换短词，不许缩字号或折行硬塞。
7. SVG 的 viewBox 宽高比与其 CSS 宽高比一致。比例不同时浏览器会等比缩放并留白，图形整体偏移，箭头尖端落不到目标边上。

## 尺寸与字号
1. 先定画布宽，再按最长标签反推字号，最后量画布高。不许先定高度再往里面挤字。盒子的宽度按框内最长一行文字反推，不按画布宽度铺满；铺满会产生大量空白的卡片。
2. 最小字号下限：单栏 88.5mm 时 7pt，整幅 185mm 时 6pt。低于下限就压缩表述、改骨架或加画布，不许缩字，也不许删对象。
3. 字号最多 4 档，相邻档差不超过 1.5pt。上下标与单位符号不计入档位，统一取父级字号的 0.7 倍。
4. 线宽最多 4 档：0.15 分隔线、0.26 箭头与小卡片、0.32 面板、0.4 外框，不取中间值。
5. SVG 内的文字按 viewBox 单位换算成 pt 后同样受最小字号约束，自检时不得跳过。
6. viewBox 取 1 单位等于 1mm 时，字号直接写毫米：6pt 约 2.12mm，7pt 约 2.47mm。
7. 字号下限按最终印刷宽度核算，不按画布宽度核算。跨栏缩放会同时改变字号：185mm 图缩到 137.6mm 是 0.744 倍，6pt 只剩 4.5pt；88.5mm 图放到 137.6mm 是 1.55 倍，7pt 变 10.9pt。混用两种画布宽度前先算这一步。

## 配色
1. 语义色数量等于要区分的分组或角色数；没有需要区分的维度就保持中性。
2. 一色两档：深色文字加极浅填充。
3. 颜色只编码语义，不做装饰。同一个颜色在同一张图里只表示同一件事。跨图不要求沿用同一套色义，每张图各自成立即可。
4. 一张图里两种语义都要上色时，把颜色留给这张图要论证的那一方，另一方用位置、标签、行序区分。
5. 颜色面积要小。彩色用在描边、色点、短文字上，卡片和框一律白底或最浅一档填充。整块彩色填充会让同样的色值显脏，这是同一套颜色在不同图上观感差异最大的原因。
6. 禁用渐变、投影、发光、玻璃拟态。

## 内容红线
1. 内容清单里列出的对象必须全部出现，条数由清单决定，不设"一张图一个主题"的上限。只允许因为兄弟图已经画过而移出，不允许因为排版困难而删除。排不下就改骨架、改列宽、改画布高度，不许减内容。
2. 不出现我没给的数字，不写约、大约、示例。
3. 不用示例模型名、示例比例、占位百分比。缺内容宁可留空并告诉我。
4. 图内不出现图号、标题、题注，这些写在论文里。
5. 不画没有语义的箭头、回环、装饰线。
6. 术语用我给的原文，不自行改写或扩写。
7. 不在本图重复兄弟图里已有的数字、曲线、矩阵；需要引用时只写名字，不重画。
8. 数字要么写具体数据集，要么不写；不许把某一个数据集的数值改写成「每套」「每个」去覆盖同类数据集。

## 做完先自检，逐条核对
1. 画布尺寸与 @page 一致，导出后完整不裁。
2. 最小字号达到下限。
3. 全部面板顶边与底边对齐，误差为 0；同一行卡片同高。
4. 没有文字溢出容器，没有文字压线，没有两行重叠。
5. 面板内空白高度不超过该面板高度的 15%。
6. 图里每个数字都能在我给的输入里找到出处。
7. 导出的图单独打开就是一个完整单元：没有页面底色、没有正文标题，不读上下文也能看出它分为几组。
8. 量四边留白：上、左、右、下四个间距数值相等，最后一件元素不贴边框。
9. 箭头杆宽 0.26mm 到 0.3mm，三角长度不小于杆宽的 4 倍，同一类箭头同一尺寸，没有块状或墨点状箭头。
10. 同类箭头两端到元素的距离实测相等，不存在一端贴着、一端留缝的混排。
11. 彩色面积不超过全图 5%，没有整块彩色填充。
12. 本图没有重复兄弟图的数字、曲线、矩阵。
13. 每个文本节点只占一行。刻意写的两行注脚要在图上单独标出；其余出现换行即不通过——溢出检测抓不到「变高」。
14. 实测组内间距与组间间距，后者不小于前者的 2 倍。
15. 实测同类箭头尖端到目标边的距离为 0。

## 报告
给我文件路径、画布尺寸、最小字号、导出命令；另给五项：选了什么骨架及理由、压缩或合并了哪些表述及理由、移出了哪些对象及理由（仅限兄弟图已承载，不得删除）、与默认值不同的地方及理由、需要我确认的空白或省略。
```

## 三、 单独使用说明 (Standalone Usage)

若你想脱离本项目单独使用本提示词：
1. 复制上方“核心转换提示词规范”代码块内的全部文本；
2. 在任意 AI 客户端（如 Claude, ChatGPT, Cursor, Windsurf）中发送；
3. 将你的要画内容（命题、结构、文字、数字、载体尺寸）填入对应的占位符后提交；
4. AI 将直接输出对应的单文件、内联 CSS+SVG、纯静态 HTML 代码，浏览器打印 100% 即可直接插入论文！
