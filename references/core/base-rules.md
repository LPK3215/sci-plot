# 底座物理法则与防翻车红线 (Base Physics & Guardrails)

无论选择何种风格、期刊或外部规范，所有生成的生图提示词**必须严格遵守**以下物理层底线约束，防止文生图模型（DALL-E、Midjourney、Stable Diffusion 等）翻车乱码或失控。

---

## 一、 图像物理规格

- **默认画幅**：纵向 2:3（方法架构图、机制展开图的标准出版比例）
- **幻灯片/展示画幅**：横向 16:9 或 4:3（适合 README Hero、PPT 答辩）
- **文字清晰度**：所有标签必须清晰可读，严禁密集长句

---

## 二、 构图与空间信息层级

1. **三层构图原则**：
   - **标题区（Top）**：顶部单行简洁说明主题（如 "Method Overview: Sparse Transformer"）。
   - **主体区（Main Body）**：占画面 **75% ~ 85%** 的绝对视觉重心，严禁主体过小。
   - **标注区（Annotation）**：紧贴对应节点短字解释，绝不允许重叠遮挡。
2. **留白率控制**：
   - 严禁画面空洞（留白超过 25% 必须补充张量维度信息、小矩阵网格、计算热力图或前后对比）。
   - 严禁信息过载（一张图只讲透一个核心机制，复杂结构必须拆页）。
3. **视觉流动与导向**：
   - 清晰的方向性（从左到右、或自底向上流动）。
   - 必须使用箭头（主干粗线 2~3px，残差/辅助细线 1px）或数字序号（① ② ③）引导阅读顺序。

---

## 三、 文字标注防乱码红线（核心安全绳）

生图模型画文字极易乱码，必须遵循以下“极短法则”：
- **标签数量限制**：单张图关键标签数量控制在 **8 ~ 12 个以内**。
- **标签长度限制**：中文每个标签 ≤ 8 个汉字；英文每个标签 ≤ 3 个单词。
- **术语保留英文**：专业术语（如 `Attention`, `Encoder`, `Embedding`, `Residual`）统一保留英文。
- **严禁长段落**：绝不允许在图片中出现连续两行以上的长句解释，所有说明均为独立短字。

---

## 四、 色彩克制法则

- **颜色总量**：**主色 + 强调色，全图严格不超过 3 种颜色**。
- **纯色无渐变**：严禁炫目渐变色，严禁高饱和度荧光色。
- **色彩语义明确**：
  - 黑色/深灰（#1A1A1A / #333333）：主体线框、主要结构与数据流向。
  - 强调色（如科技蓝 #2563EB 或 琥珀橙 #D97706）：**专用于标记本图唯一的创新点或核心路径**，绝不用于装饰。

---

## 五、 全局绝对禁止项 (Negative Guardrails)

- [x] **严禁代码块**（禁止在图中画代码片段，代码由文章正文承担）
- [x] **严禁拟物与照片级渲染**（无 3D 浮夸球体、无写实阴影材质、无光影杂乱背景）
- [x] **严禁无意义装饰**（禁止与学术内容无关的花纹、底纹边框、科幻光效）
- [x] **严禁大面积纯黑背景**（默认纯白 #FFFFFF 或学术浅灰 #F8F9FA 背景）

---

## 六、 标准输出提示词模版 (Prompt Template)

所有生成的单页提示词文件，必须严格采用以下结构：

```markdown
# Page [序号]: [主题名称]

## Metadata
- **Type**: [cover / method-overview / mechanism-detail / comparison / evidence / architecture]
- **Style/Source**: [选定的规范来源]
- **Language**: [en / zh]
- **Aspect Ratio**: [2:3 / 16:9 / 4:3]

## Composition Description
[清晰描述空间布局：主体分布、箭头流向、模块相对位置]

## Content Elements
- [模块名称与张量维度信息]
- [流向箭头与残差连线]
- [核心高亮标注]

---

## ▶ English Prompt (Core — Copy Directly)
[一段高浓度、结构化、符合选定规范并带有防翻车负向约束的英文 Prompt，供用户直接复制]

## ▶ 中文提示词（备用）
[对应的中文提示词，适用于支持中文文生图工具如豆包、通义万相]
```
